## Project Description

The Pangasinan Heritage Digital Showcase is a static web application that presents selected heritage sites and natural attractions in Pangasinan. The website features information about Hundred Islands, Bolinao Lighthouse, and Balungao Hot Spring.

The project was developed using Next.js and deployed as a static website through GitHub Pages.
